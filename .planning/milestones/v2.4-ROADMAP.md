## Constraint Discoveries This Milestone

- **Idiomatic F# 1/5 was a Python-transcript artifact (Phase 28 disprove):** v2.1-era scoring used HumanEval+ Python answers (chat-mode-wrapped). v2.4 F# fixture rescore yielded 5/5. Lesson: when scoring quality dimensions, ensure the evidence corpus matches the dimension category.
- **5th macOS bash-strict-mode pattern (Phase 28-01 audit):** `grep -oE` in pipelines exits 1 on zero-match; `pipefail` propagates before downstream guard can run; fix is `|| true` at end of pipeline. Real bug found at `bench/eval-qwen35-122b.sh:378` during HARNESS-AUDIT pass; fixed in commit `94d905c`.
- **FSI fixture skeleton pattern (Phase 28-02):** `dotnet fsi <file>.fs </dev/null` always exits 1 on interactive EOF; compile verification uses absence of `error FS` in output, not exit code. Fixtures use direct top-level `try...with` (no `[<EntryPoint>]` since FSI doesn't invoke it). Documented in STATE.md as load-bearing for future F# fixture work.
- **Sum-then-scale band tables beat round(average) for multi-fixture rubrics:** caught during plan-checker iter-1. For [5,5,0]: average rounds to 3 (loses signal); sum-band gives 4 (preserves signal).
- **Conditional SKIP-by-design pattern (Phase 29):** never-created phase directory is structurally cleaner than BLOCKED-with-record. Use Path-A SKIP when conditional doesn't trigger; use BLOCKED preservation when partial-attempt produces diagnostic value.
