<objective>
Move v1.2's `/tmp/bench-v1.2/run.sh` into the repo at `bench/run.sh`, consolidate its
seven case-statement selectors into mode-flag dispatch, relocate the two untracked
fixtures into `bench/fixtures/`, add a third fixture for the B2 divide-by-zero case,
and add a `## Bench` section to CLAUDE.md.

Purpose: Without `bench/` in-repo, every regression catch and fix in v1.2 was validated
against an ephemeral `/tmp/`-anchored script. This plan makes the harness regressable
by tracking it in git. It is the foundation Plans 10-02 (--gate + baseline.json) and
10-03 (documentation/bench.md) build on.

Output: A new `bench/` directory tree containing `run.sh` plus three fixture files,
an additive CLAUDE.md update, and a `.gitignore` line for `bench/runs/`. No `--gate`
mode yet — that lands in Plan 10-02.

- This phase is bench-only. Do NOT modify anything under `src/` or `tests/`.
- `git mv` is unnecessary for `bench-fixtures/{bug_lastchar.fs,bug_average.fs}` because
  those files are currently untracked. Use `mv` then `git add bench/fixtures/...`. Then
  `rmdir bench-fixtures/` to delete the now-empty directory.
- macOS bash 3.2 is the target. NO `declare -A`, NO `${VAR^^}`, NO `[[ =~ ]]` with
  BASH_REMATCH arrays. The lifted v1.2 script is already 3.2-compatible — preserve that.
- `set -u` only. Do NOT add `set -e` (would abort the run on the first failing test).
- The `LOG_DIR="$LOG_DIR" run ...` env-prefix pattern in v9_1_rev/rev2 should be
  REPLACED with a clean `local LOG_DIR=...` at function top. The lifted run() helper
  reads the calling-function-scope `LOG_DIR` since bash dynamically scopes `local`.
