<objective>
Replace Qwen 2.5-era sampling parameters in the LLM client with Qwen 3.5 model-card values
(temperature=0.7, top_p=0.8, top_k=20, presence_penalty=0.0). Raise the HTTP timeout from 180s to 300s
to cover Qwen 3.5 122B cold-start scenarios. Introduce a `SamplingParams` record in Domain.fs and a
`modelToSamplingParams` function in Router.fs; deprecate `modelToTemperature`.

Purpose: Align blueCode's POST body with the documented Qwen 3.5 non-thinking coding configuration so
inference is calibrated for the canonical 122B target (not the retired Qwen 2.5 32B/72B pair). The 300s
timeout removes a known false-positive `LlmUnreachable` path on cold-start after `launchctl kickstart`.

Output: 4 atomic commits (Domain type + Router function + Cli adapter rewire + timeout/comments/docs),
bench gate 6/6 PASS, test suite 262/1/0 stable.
</objective>

<decisions>
**SamplingParams shape (resolves RESEARCH OD-1):** Use a **record in `Domain.fs`**
(`type SamplingParams = { Temperature: float; TopP: float; TopK: int; PresencePenalty: float }`).
Rationale: consistent with `LlmRequest`/`Step`/`Plan` etc. already in Domain. Core stays pure
(no Http knowledge — record is just data). `Router.modelToSamplingParams : Model -> SamplingParams`
returns the record per model. `QwenHttpClient.buildRequestBody` consumes it.

**modelToSamplingParams arity (resolves RESEARCH OD-2):** Per Qwen 3.5 non-thinking coding model
card, both 35B and 122B share identical sampling parameters (temp=0.7, top_p=0.8, top_k=20,
presence_penalty=0.0). The function returns the same record for both DU cases — but uses an explicit
two-case pattern match (NOT a wildcard `| _ ->`) to preserve compile-time exhaustiveness per
CLAUDE.md convention. Future per-model tuning is a one-line change.

**modelToTemperature deletion:** No tests reference `modelToTemperature` (verified via RESEARCH:
RouterTests.fs covers `classifyIntent`, `intentToModel`, `modelToEndpoint`, `endpointToUrl` only).
Safe to remove entirely. Single call site is `QwenHttpClient.fs:68` which is rewired in Task 3.
</decisions>
