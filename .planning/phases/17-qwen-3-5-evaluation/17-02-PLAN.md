<objective>
Execute the service swap from Qwen 2.5 32B/72B → Qwen 3.5 35B/122B, capturing empirical load-test data and verifying the thinking-mode mitigation works. This plan is `autonomous: false` — it has 4 user checkpoints because the steps require either local-resource access the executor cannot have (model download wait time + disk space verification) or genuinely-irreversible operational changes (launchctl unload of currently-running production services).

Purpose: This is the bridge plan. 17-01 wrote the runbook; 17-03 runs the bench comparison. 17-02 actually flips the services and produces the empirical evidence needed to commit to (or reject) the new pair. The output of this plan is `17-02-LOAD-TEST.md` — a numbered record of what happened, with timestamps, RSS samples, and the canonical smoke-test response captured verbatim. This artifact becomes the input for 17-03's decision matrix.

Output:
- New file `.planning/phases/17-qwen-3-5-evaluation/17-02-LOAD-TEST.md` (~60-150 lines) with sections for each checkpoint's captured data.
- POSSIBLY modified `src/BlueCode.Cli/Adapters/QwenHttpClient.fs` IF AND ONLY IF Path A is empirically broken at Checkpoint 4. The Path B patch is ~1 line added to the request anonymous record.
- 4 user-facing checkpoints (CP1-CP4) gating the swap.
- 1 canary bench invocation as the final automated gate before declaring 17-02 done.
- Atomic commits per CLAUDE.md commit-protocol convention: `chore(17-02): ...` for ops + docs commits, `feat(17-02): ...` if Path B is engaged.

Operating constraint (CRITICAL): The launchctl operations are reversible (plists stay on disk). The model file downloads are large (~90 GB) and time-consuming (network-bound). The executor MUST NOT delete old model files at `~/llm-system/models/qwen{32b,72b}/` (rollback). The executor MUST NOT delete old plists at `~/Library/LaunchAgents/com.ohama.qwen{32b,72b}.plist` (rollback). The executor MUST NOT use `launchctl kill` or `kill -9` on the running mlx_lm.server processes — `launchctl unload` is the documented way (KeepAlive=true means kill-9 results in instant respawn). 17-02's destructive footprint is ZERO if rolled back.
