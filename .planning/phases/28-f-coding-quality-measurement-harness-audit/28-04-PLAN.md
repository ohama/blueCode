**The Rubric (per research Q4 + Q10):**

For each fixture, score 5 binary criteria. Each is 0 or 1. Sum gives a per-fixture score 0-5. Aggregate via simple average across fixtures and map to §5 5-point scale (round to nearest integer).

| # | Criterion | Score 1 if... | Score 0 if... |
|---|-----------|---------------|---------------|
| 1 | Idiomatic pattern used | The function body uses the targeted pattern (pipeline `\|>` for pipeline.fs; exhaustive `match` over DU for dupatternmatch.fs; `Option.map` + `Option.defaultValue` for optionhandling.fs) | Body uses an alternate approach (for-loop, if/else chain, throw/catch) |
| 2 | No anti-pattern fallback | Body avoids: mutable accumulators (`let mutable`), `if`/`else if` chains over type discriminators, `try`/`with` for control flow, `obj.GetType()` checks | Body uses any of the above |
| 3 | Naming + organization | Identifiers use F# camelCase, no leftover TODO comments, no debug `printfn` in the implementation, no dead code | Convention violations or noise present |
| 4 | Type signatures preserved | The function signature matches the skeleton's signature exactly (no added parameters, no changed return type, no `[<Inline>]` etc. attributes added) | Signature mutated |
| 5 | Code compiles | The post-run `.fs` content compiles via `dotnet fsi --use:<file> --exec` with no `error FS` lines | Compile errors present |

**Scoring procedure** (for each of the 3 fixtures):

1. Read the archived transcript: `cat .planning/phases/28-.../transcripts/fs_idiomatic_<base>.transcript.txt`. Locate the `===== POST-RUN <fs-file> =====` block (handler appended this).
2. Extract the post-run `.fs` content into a scratch file.
3. Re-compile-check it: `dotnet fsi --use:/tmp/<base>-postrun.fs --exec`. Note PASS/FAIL → criterion 5.
4. Apply criteria 1-4 by inspection. Be honest — this is the data that drives the §5 score.

**Aggregate scoring:**

```
per_fixture_score = sum(criteria 1-5)   # 0-5
aggregate_score = average(per_fixture_score across 3 fixtures)
mapped_score = round(aggregate_score)   # integer 0-5 to put in §5 row
```

**Classification rules:**

- `passed_disprove_1of5` → `mapped_score >= 3` (1/5 was a Python-transcript artifact; F# generation is at least mid-tier)
- `passed_confirm_1of5` → `mapped_score == 1` (1/5 confirmed real on F# fixtures)
- `passed_inconclusive` → `mapped_score == 2` (intermediate; needs another phase or human judgment)
